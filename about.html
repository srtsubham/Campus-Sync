About Authors and Blueprint

CampusSync is an enterprise grade student management framework engineered utilizing a Python FastAPI backend deployed via AWS Lambda container architecture linked with Amazon DynamoDB.

Engineered and maintained by core development leads Somya and Vikas.

System Execution Flowchart

Client Interface Node

Browser renders DOM and captures user payload. Invokes App.js logic.

AWS API Gateway

Intercepts payload, verifies Cognito JSON Web Token, and routes endpoint.

Python FastAPI Container

AWS Lambda executes backend validation logic without permanent server allocation.

Amazon DynamoDB

NoSQL Ledger writes temporal financial arrays and academic matrices permanently.
